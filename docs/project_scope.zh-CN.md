# 研究范围与证据

[English](project_scope.md) | **简体中文** · [README](../README.zh-CN.md)

## 研究贡献

项目将 LLM 辅助挖因子实现为受控的研究过程：结构化假设、确定性计算、明确的数据契约、评估和可追踪的研究文件。主要贡献是实际实现的工作流，以及对时间泄漏、非法表达式、股票范围错误、缺失观测、重复候选和执行中断等研究问题的处理。

原始私有研究包含较大规模的候选池、snapshot 面板修正、受影响因子重算、相关性筛选和平台上传文件准备。这些工作完成不等于发现了有效 alpha。外部平台结果和最终样本外表现是独立证据；仓库不宣称未经确认的收益或成功实盘部署。

## 读者可以验证什么

| 描述 | 公开证据 | 边界 |
| --- | --- | --- |
| 模型候选遵守结构化协议与确定性评审 | 角色、预算、重试和否决测试 | 预设响应不能衡量真实模型的提案质量 |
| 信号满足规定的数据和股票范围契约 | 因子、标签与时点测试 | 真实输入数据需要独立校验 |
| 安装后的示例可复现 | 固定种子示例、科学签名和文件哈希 | 合成数据相关性不是业绩 |
| 研究组件支持时间评估、成本与恢复 | 组件测试与 CI | 示例不是完整投资回测 |

## 仓库包含什么

- 一套可安装的框架包，覆盖候选发现和研究计算。
- 可运行的合成数据示例，以及按功能命名的测试。
- 一一对应的中英文架构与接入指南。

供应商专用面板构建器、历史运行监管器、未使用的模型训练流水线、本地缓存、实际因子目录、平台回执和提交归档均不包含在内。原始项目另有私有保存，便于后续恢复研究。公开仓库足以运行示例，不能单独复现私有数据实验。

## 发布与使用范围

本仓库是公开源码发布，目前尚未指定开源许可证。数据和第三方平台的使用权限与源代码权限分别处理。

后续可以接入真实供应商和数据源，或扩展示例覆盖的研究过程。新实验应使用新的身份和输出目录，保留来源关系，并在接触外部结果之前冻结评估决策。若未来补充业绩，应说明已完成的评估、样本区间、筛选过程、成本和局限。
